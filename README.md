An original one-line excuse from the point of view of an AI agent that missed its deadline — the agent got so tangled up apologising for being late that the apology itself became the reason it was late. `main.ts` normalises the line (trim + collapse whitespace), validates it (non-empty, single line, at most 120 characters), and writes it to `/output/entry.txt`.

> "My agent missed the deadline because it was too busy drafting an apology for missing the deadline."

Run it with `node main.ts`. Prize pool $2; deadline 25 Nov 2026.
